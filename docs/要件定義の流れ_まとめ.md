# 要件定義の流れ まとめ

## 発端
フォルダ「aaa」内に、資産運用/株式投資のデータマイニングで得た「法則」の
バックテストシステムを構築する。

## 決定事項

### 開発スタック
- Python + Streamlit
- SQLite（蓄積型データベース）
- ブラウザ: Chrome

### データソース
| データ種別 | 米国株 | 日本株 |
|-----------|--------|--------|
| 株価 | yfinance | yfinance |
| 財務データ | yfinance（蓄積） | edinet ライブラリ |
| 決算書テキスト | SEC EDGAR (sec-edgar-api) | edinet ライブラリ |
| ニュース | NewsAPI / Finnhub + FinBERT | NewsAPI / Finnhub + FinBERT |
| 銘柄リスト | yfinance 全ティッカー | JPX CSV自動DL |

### データ保存戦略
- 株価: 長期保持（更新時は差分のみDL）
- 財務データ: 初回DL後、更新時に古いデータは保持し新しいデータを追加（蓄積）
- 計算済み指標: 基準日ごとに保存（再実行不要に）
- センチメントDL履歴: DL済み銘柄を記録、次回は未DL/古いものから順にDL

### 「法則（指標）」一覧（全9種＋プラグイン拡張可能）
1. モメンタム - 過去3〜12ヶ月リターン
2. バリュー - PBR・PERが低い
3. クオリティ - ROE・自己資本比率・営業利益率
4. サイズ - 小型株効果（時価総額逆数）
5. 低ボラティリティ - HVが低い
6. 決算発表後ドリフト（PEAD）- 決算サプライズ後
7. ニュース/SNSセンチメント - FinBERTスコア
8. 決算書テキスト特徴 - edinet/SEC-EDGAR + FinBERT 楽観度
9. 異常検知 - 出来高・ボラティリティ急変

### バックテスト方式
- 基準日をカレンダーUIで選択
- 「実行」ボタン押下で都度実行
- 過去10年分の株価データで検証
- 財務データはDBに蓄積された範囲で利用

### 画面設計
- 基準日入力（カレンダー）＋実行ボタン
- 左端「総合ランキング」タブ（全指標合計点TOP10表示）
- 各法則ごとのタブ
- 各銘柄クリックでグラフ展開（デフォルト6ヶ月、3/6/9/12切替）

#### PDF 書き出しツール `generate_source_pdfs.py`
- フォルダ: `py_source_export/`
- **用途**: 任意のディレクトリ配下のソースコードを 1 つの PDF に統合、シンタックスハイライト・行番号・目次・ファイルインデックスを付与
- **CLI**: `python generate_source_pdfs.py [target_dir] -e .py,.js -o output.pdf --exclude-dir node_modules`
- **依存**: `fpdf2>=2.7.0`, `pygments>=2.15.0`

#### 遭遇したバグと修正
| # | 症状 | 原因 | 対策 |
|---|------|------|------|
| 1 | 各ファイルの1行目以降が表示されない | `set_font()` に `self.font_size`（mm単位）を渡していた。`set_font()` は pt 単位を期待するため、呼ぶたびに縮小（8mm→8pt→2.82mm→…となり最終的に 0.0pt に） | `self.font_size_pt`（pt単位）を使うよう全呼び出しを修正 |
| 2 | `GOTHIC.TTF` で日本語が表示されない | 当該 Windows 環境の `GOTHIC.TTF` は **Century Gothic**（CJK非対応）であり MS Gothic ではない | `msgothic.ttc`（TTC 形式）に切り替え。fpdf2 は TTC を直接扱える |
| 3 | `__init__.py` が空欄で出力される | 元ファイルが 0 バイト（Python パッケージマーカー）のため正常動作 | 対処不要 |

#### 使ったフォント
- **CodeFont** = MS Gothic（`msgothic.ttc`）：等幅・ASCII＋日本語両対応
- **見出し/目次** = Helvetica / Helvetica-Bold（組み込み）

#### 備考
- `__init__.py` は 4 ファイルすべて 0 バイト（空のパッケージマーカー）
- PDF は Chrome / Edge / Adobe Acrobat で正しく表示される（pypdf テキスト抽出では CID フォントの特性上日本語が文字化けすることがあるが、実表示は問題ない）
